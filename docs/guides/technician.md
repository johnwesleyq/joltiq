# Technician guide
- **Queue**: open tickets include escalated ones. Filter by *Assigned to me*. Overdue SLA is shown in red.
- **Ticket view**: the assistant panel shows the plan with policy-assigned risk, sources (internal citations, web sources with reliability and flags), hypotheses, diagnostics, state history, verification results and cost.
- **Take over**: *Take over (escalate)* stops the assistant. In live sessions, *Take control* preempts the AI (the customer can always preempt you).
- **Research**: Console → Research for manual lookups. Queries are redacted before leaving the platform.
- **Knowledge**: review AI-drafted articles. Only an admin can publish an article as a *runnable procedure*, and only from a verified fix that isn't based solely on web research.
